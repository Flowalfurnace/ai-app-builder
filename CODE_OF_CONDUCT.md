## 🪄 Turn Words into Working Software

**AI App Builder** is a revolutionary, full-stack development environment that transforms natural language prompts into fully functional, production-ready web applications. 

Forget about spending weeks setting up boilerplate, configuring databases, and writing repetitive CRUD APIs. With AI App Builder, you simply describe what you want — "A SaaS dashboard with user authentication, Stripe payments, and a task list" — and the AI generates the entire codebase, installs the dependencies, and spins up a live preview instantly.

It’s not just a code generator; it’s an autonomous developer. It creates React components, writes the backend API routes, configures the SQL database schema, and even writes the CSS to make it look beautiful. You stay in the driver's seat, able to tweak the generated code or ask the AI to make adjustments in real-time.

> 💡 **Why use AI App Builder?** Because the barrier between an idea and a shipped product should be zero. Prototype in minutes, iterate in seconds, and focus on your product's logic while the AI handles the syntax.

## 🚀 Quick Start

> **Three steps. Under two minutes. No installation required.**

### 1️⃣ Launch the workspace
Click the **Launch Builder** button at the top of this README to open the web IDE.

### 2️⃣ Write your prompt
In the chat interface, describe the app you want to build. For example:
`> Build a to-do list app with priority tags and a dark mode toggle.`

### 3️⃣ Refine and deploy
Preview the app in the right panel. If you want changes, just ask the AI (e.g., "Make the buttons rounded"). Once ready, click "Deploy".

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🖥️ **Frontend UI** | Split-pane IDE, live preview iframe | `React` + `CodeMirror` |
| 🧠 **AI Engine** | Orchestrates LLM prompts and code generation | `GPT-4o` / `Claude 3.5` |
| 🏗️ **Sandbox** | Compiles and runs the generated code safely | `WebContainers` |
| 🚀 **Deployment** | Pushes to production seamlessly | `Vercel API` |

</div>

The magic happens via WebContainers. When the AI generates code, it runs natively in your browser, meaning you get instant hot-reloading and error logs fed directly back to the AI model for self-correction.

## ❓ Frequently Asked Questions

<details>
<summary><b>Do I need to know how to code?</b></summary>

No. The app is designed for non-technical founders to build MVPs quickly. However, if you *do* know how to code, you can manually edit the generated files and the AI will adapt to your changes.
</details>

<details>
<summary><b>Who owns the code?</b></summary>

You do. The entire codebase is generated and hosted in your workspace. You can export it to GitHub at any time and claim full ownership.
</details>

<details>
<summary><b>Can I use my own API keys?</b></summary>

Yes. You can bring your own OpenAI API key to power the builder, which reduces your subscription costs and gives you more control over the models used.
</details>

<details>
<summary><b>What happens if the AI makes a mistake?</b></summary>

The AI has an auto-correction loop. If the generated code throws an error in the WebContainer, the error is sent back to the AI, which rewrites the code to fix it automatically.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include your browser version and a screenshot of the prompt and the resulting error.
</details>
